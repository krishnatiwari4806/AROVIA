<threat_model>
### Security Threat Model (ASVS L1)
- **T-01-01 (Credential Exposure / Unsafe Defaults):** Risk of hardcoded secrets or fallback default API keys in source code. Mitigation: Pydantic `BaseSettings` enforces required `SECRET_KEY` (min 32 chars), `DATABASE_URL`, and `GEMINI_API_KEY` without defaults; `.env.example` contains only dummy placeholders.
- **T-01-02 (Unsanitized System Data Leakage):** Risk of leaking database connection strings or internal hostnames in `/health` responses. Mitigation: Health endpoint returns only status enum (`healthy`/`unhealthy`) and static version without sensitive connection metadata.
</threat_model>
