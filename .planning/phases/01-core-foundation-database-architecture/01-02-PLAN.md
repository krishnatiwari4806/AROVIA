<threat_model>
### Security Threat Model (ASVS L1)
- **T-01-03 (Internal Error Information Leakage):** Uncaught 500 exceptions leaking database queries, table names, file system paths, or Python stack traces to clients. Mitigation: Global exception handler in `app/core/exceptions.py` intercepts `Exception`, logs the full traceback internally, and returns a sanitized payload `{"detail": "Internal server error", "error_code": "INTERNAL_ERROR"}` with HTTP status 500.
- **T-01-04 (Input Schema Tampering):** Invalid JSON types or extra parameters bypassing payload checks. Mitigation: Custom `RequestValidationError` handler formats Pydantic validation errors clearly into 422 responses with sanitized field paths.
</threat_model>
