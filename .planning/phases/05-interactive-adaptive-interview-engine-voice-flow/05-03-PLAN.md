# Phase 05: Plan 03 — Frontend Interactive Voice Interview Room (Web Speech API)

**Implement the browser-native voice interview room using React, Vite, and the Web Speech API with TTS auto-play, real-time STT microphone dictation, soft pacing countdown timer, and turn progression.**

---

## Tasks

### Task 1: Web Speech API Custom Hooks (₹0 Zero Cost)
- Create `frontend/src/hooks/useSpeechSynthesis.ts` (or `.js`):
  - Uses `window.speechSynthesis` and `SpeechSynthesisUtterance`.
  - Methods: `speak(text, onEnd?)`, `cancel()`, `isSpeaking`.
  - Graceful no-op on unsupported browsers.
- Create `frontend/src/hooks/useSpeechRecognition.ts` (or `.js`):
  - Uses `window.SpeechRecognition` or `window.webkitSpeechRecognition`.
  - Methods: `startListening()`, `stopListening()`, `isListening`, `transcript`, `error`, `isSupported`.
  - Appends speech results continuously to allow smooth live dictation.

### Task 2: Pacing Timer & Audio Visualizer Components
- Create `frontend/src/components/interview/TurnTimer.jsx`:
  - Receives `budgetSeconds` (120s or 180s) and `onTick(elapsedSec)`.
  - Visual color shift: Normal (Green/Neutral) $\rightarrow$ Amber at <= 30s $\rightarrow$ Red at 0s with soft warning banner ("Suggested time reached — wrap up your answer").
- Create `frontend/src/components/interview/AudioVisualizer.jsx`:
  - Displays dynamic speaking/listening wave pulse animation when AI is reading or candidate is speaking.

### Task 3: Interactive Interview Room & Turn Workflow
- Create `frontend/src/components/interview/InterviewRoom.jsx`:
  - Fetches active session and calls `POST /sessions/{id}/start` on room entry.
  - Auto-speaks new question prompt using `useSpeechSynthesis` with Replay and Stop controls.
  - Renders active turn progress badge (e.g. "Question 2 of 6" or "Follow-up Probe").
  - Editable answer textarea with microphone toggle button (live STT dictation into textarea, full manual typing/editing support).
  - Explicit "Submit Answer" button with confirmation state and loading spinner.
  - Advances to next turn seamlessly or renders "Interview Complete — Evaluating Answers" screen once `is_interview_complete` is true.
