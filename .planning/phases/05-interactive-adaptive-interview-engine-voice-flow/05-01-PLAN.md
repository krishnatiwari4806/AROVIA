# Phase 05: Plan 01 — Backend Adaptive AI Engine & Structured Prompt Chaining

**Implement Google Gemini structured question generation, multi-context fusion, and adaptive follow-up decision engine in `GeminiService` using the `google-genai` SDK.**

---

## Tasks

### Task 1: Pydantic DTO Schemas for Turns & AI Decisions
- Update `backend/app/schemas/interview.py`:
  - `GeneratedQuestion`: `question_text: str`, `ideal_answer: str`, `primary_concept: str`
  - `NextTurnDecision`:
    - `is_follow_up: bool`
    - `follow_up_reasoning: Optional[str]`
    - `question_text: Optional[str]`
    - `ideal_answer: Optional[str]`
    - `primary_concept: Optional[str]`
    - `is_interview_complete: bool`
  - `InterviewQuestionTurnResponse`:
    - `id: str`, `session_id: str`, `turn_index: int`, `question_type: str`, `question_text: str`, `candidate_answer: Optional[str]`, `is_follow_up: bool`, `parent_turn_id: Optional[str]`, `ideal_answer: Optional[str]`, `turn_duration_sec: Optional[int]`, `created_at: datetime`
    - `model_config = ConfigDict(from_attributes=True)`
  - `TurnAnswerSubmissionRequest`:
    - `candidate_answer: str = Field(..., min_length=1, max_length=10000)`
    - `turn_duration_sec: Optional[int] = Field(None, ge=0, le=3600)`
  - `TurnAnswerSubmissionResponse`:
    - `session_id: str`
    - `current_turn_index: int`
    - `session_status: str`
    - `is_interview_complete: bool`
    - `next_turn: Optional[InterviewQuestionTurnResponse]` = None

### Task 2: Gemini Adaptive Generation & Multi-Context Fusion
- Update `backend/app/services/gemini_service.py`:
  - Add `INITIAL_QUESTION_PROMPT_TEMPLATE`:
    - Ingests `target_role`, `seniority_level`, `interview_focus`, `focus_skills`, `parsed_jd_data`, `resume_data`.
    - Produces `GeneratedQuestion` using `response_schema=GeneratedQuestion`.
  - Add `ADAPTIVE_NEXT_TURN_PROMPT_TEMPLATE`:
    - Ingests full interview state: session role/seniority, current turn (`question_text`, `candidate_answer`), transcript history, `remaining_core_questions`, `remaining_followup_budget`, `prior_turn_was_followup`.
    - Enforces rules:
      - If `prior_turn_was_followup` is True OR `remaining_followup_budget <= 0`: Must generate next core question (or conclude if core questions exhausted).
      - Evaluates whether answer was shallow or warranting technical depth before triggering follow-up.
    - Produces `NextTurnDecision` using `response_schema=NextTurnDecision`.
  - Implement `generate_initial_question(...) -> GeneratedQuestion` with 1 retry and fallback.
  - Implement `evaluate_and_generate_next_turn(...) -> NextTurnDecision` with 1 retry and fallback.

### Task 3: Unit & Mock Tests for Adaptive AI Engine
- Create `backend/tests/test_interview_adaptive_engine.py`:
  - Test initial question generation prompt formulation and schema parsing.
  - Test adaptive follow-up decision triggering when answer lacks depth.
  - Test forced advancement to next core question when prior turn was already a follow-up or follow-up budget is exhausted.
  - Test interview completion decision when all core questions are answered.
  - Test fallback resilience on transient AI outages.
