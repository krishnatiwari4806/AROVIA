# Phase 03: Plan 02 — Gemini Structured Skill Extraction & Resume Management CRUD Endpoints

**Implement Gemini structured JSON skill parser with Pydantic schema validation, transient retry logic, clean HTTP 503 resilience, ResumeService lifecycle management (automatic replacement, disk deletion), and secure REST endpoints (`/upload`, `/me`, `/me/parsed`, `/me`).**

---

## Tasks

### Task 1: Pydantic DTO Schemas
- Create `backend/app/schemas/resume.py`:
  - `EducationItem`: `institution: str`, `degree: Optional[str]`, `graduation_year: Optional[str]`
  - `ParsedResumeData`:
    - `skills: list[str]`
    - `experience_years: float`
    - `domains: list[str]`
    - `education: list[EducationItem]`
    - `summary: str`
  - `ResumeParsedDataUpdateRequest`:
    - `skills: Optional[list[str]] = None`
    - `experience_years: Optional[float] = None`
    - `domains: Optional[list[str]] = None`
    - `education: Optional[list[EducationItem]] = None`
    - `summary: Optional[str] = None`
  - `ResumeResponse`:
    - `id: str`, `user_id: str`, `file_name: str`, `file_size_bytes: int`, `mime_type: str`, `parsed_data: ParsedResumeData`, `created_at: datetime`, `updated_at: datetime`
    - `model_config = ConfigDict(from_attributes=True)`
  - `ResumeUploadResponse`:
    - `message: str`, `resume: ResumeResponse`

### Task 2: Gemini Structured Parser Service
- Create `backend/app/services/gemini_service.py`:
  - `GeminiService`:
    - `parse_resume(raw_text: str) -> ParsedResumeData`:
      - Builds prompt wrapping text in `<resume_text>` tags with explicit extraction instructions.
      - Uses `google-genai` / `google.generativeai` with `model=settings.GEMINI_MODEL`.
      - Enforces structured JSON output via `response_schema=ParsedResumeData` or `response_mime_type="application/json"`.
      - Implements 1 automatic retry with exponential backoff on transient network timeouts or rate limits.
      - Raises `AppError("AI evaluation service is temporarily unavailable.", status_code=503, error_code="AI_SERVICE_UNAVAILABLE")` on unrecoverable outage.

### Task 3: ResumeService & REST Endpoints
- Create `backend/app/services/resume_service.py`:
  - `upload_resume(db: AsyncSession, current_user: User, file: UploadFile) -> Resume`:
    - Reads file stream in chunks, enforcing 5 MB limit.
    - Verifies magic bytes (`verify_file_magic_bytes`).
    - Checks if candidate already has an existing `Resume` record: deletes existing file from disk and deletes existing DB row.
    - Extracts & sanitizes text (`extract_and_sanitize_text`).
    - Calls `GeminiService.parse_resume(sanitized_text)` to extract `ParsedResumeData`.
    - Writes new file to `storage/resumes/<uuid>.<ext>` with `0600` permissions.
    - Inserts and commits new `Resume` row in database.
  - `get_user_resume(db: AsyncSession, current_user: User) -> Resume`:
    - Queries active resume for `current_user.id`. Raises `NotFoundError` if absent.
  - `update_parsed_data(db: AsyncSession, current_user: User, update_data: ResumeParsedDataUpdateRequest) -> Resume`:
    - Merges candidate edits into `resume.parsed_data` and commits.
  - `delete_resume(db: AsyncSession, current_user: User) -> None`:
    - Deletes file from disk and removes row from DB.
- Create `backend/app/api/v1/endpoints/resumes.py`:
  - `POST /upload` (with `@limiter.limit("5/minute")` and `UploadFile`)
  - `GET /me`
  - `PUT /me/parsed`
  - `DELETE /me`
- Mount resumes router in `backend/app/api/v1/router.py`.

### Task 4: Integration Tests
- Create `backend/tests/test_resume_parser.py`:
  - Unit tests for `GeminiService.parse_resume` with mock LLM responses.
  - Validates Pydantic schema deserialization.
  - Tests 1 retry on network timeout.
  - Tests clean HTTP 503 on unrecoverable error.
- Create `backend/tests/test_resume_endpoints.py`:
  - `POST /api/v1/resumes/upload` creates resume and replaces previous upload.
  - `GET /api/v1/resumes/me` returns current candidate resume and skills.
  - `PUT /api/v1/resumes/me/parsed` overrides skills and experience years.
  - `DELETE /api/v1/resumes/me` deletes disk file and database record.
  - Rate limiting verification.
