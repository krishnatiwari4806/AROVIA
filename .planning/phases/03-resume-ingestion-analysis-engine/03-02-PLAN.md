# Phase 03: Plan 02 — Gemini Structured Skill Extraction & Atomic Resume Management CRUD Endpoints

**Implement Gemini structured JSON skill parser with Pydantic schema validation using `google-genai` SDK only, transient retry logic, clean HTTP 503 resilience, atomic ResumeService lifecycle management (safe replacement order & rollback cleanup), and secure REST endpoints (`/upload`, `/me`, `/me/parsed`, `/me`).**

---

## Tasks

### Task 1: Pydantic DTO Schemas
- Create `backend/app/schemas/resume.py`:
  - `EducationItem`: `institution: str`, `degree: Optional[str]`, `graduation_year: Optional[str]`
  - `ParsedResumeData`:
    - `skills: list[str]`
    - `experience_years: float`
    - `domains: list[str]`
    - `education: list[EducationItem]`
    - `summary: str`
  - `ResumeParsedDataUpdateRequest`:
    - `skills: Optional[list[str]] = None`
    - `experience_years: Optional[float] = None`
    - `domains: Optional[list[str]] = None`
    - `education: Optional[list[EducationItem]] = None`
    - `summary: Optional[str] = None`
  - `ResumeResponse`:
    - `id: str`, `user_id: str`, `file_name: str`, `file_size_bytes: int`, `mime_type: str`, `parsed_data: ParsedResumeData`, `created_at: datetime`, `updated_at: datetime`
    - `model_config = ConfigDict(from_attributes=True)`
  - `ResumeUploadResponse`:
    - `message: str`, `resume: ResumeResponse`

### Task 2: Gemini Structured Parser Service (`google-genai` Only)
- Create `backend/app/services/gemini_service.py`:
  - `GeminiService`:
    - `parse_resume(raw_text: str) -> ParsedResumeData`:
      - Builds prompt wrapping text in `<resume_text>` tags with explicit extraction instructions.
      - Uses `google-genai` (`from google import genai`) exclusively with `model=settings.GEMINI_MODEL`.
      - Enforces structured JSON output via `response_schema=ParsedResumeData` and `response_mime_type="application/json"`.
      - Implements 1 automatic retry with exponential backoff on transient network timeouts or rate limits.
      - Raises `AppError("AI evaluation service is temporarily unavailable.", status_code=503, error_code="AI_SERVICE_UNAVAILABLE")` on unrecoverable outage.

### Task 3: Atomic ResumeService & REST Endpoints
- Create `backend/app/services/resume_service.py`:
  - `upload_resume(db: AsyncSession, current_user: User, file: UploadFile) -> Resume`:
    - **Safe Atomic Replacement Lifecycle:**
      1. `upload & validate size`: Read file stream in chunks, strictly enforcing the 5 MB limit.
      2. `validate magic bytes`: Verify binary signature (`%PDF-` or `PK\x03\x04` zip header).
      3. `extract & sanitize`: Run `pdfplumber` / `python-docx` extractor in thread pool, verify length >= 50 non-whitespace chars, strip control characters, bound at 30,000 chars.
      4. `parse with Gemini`: Invoke `GeminiService.parse_resume(sanitized_text)` using `google-genai`.
      5. `persist new file`: Write new file to `storage/resumes/<new_uuid>.<ext>` with `0600` permissions.
      6. `create/replace DB record`: Check for existing `Resume` for `current_user.id`. Note the `old_file_path` (if any). Update the existing DB record or insert a new record with new file metadata, raw text, and parsed data.
      7. `commit transaction`: Await `db.commit()` and `db.refresh(resume)`.
         - *Rollback Guard*: If `db.commit()` raises an exception, catch it, delete the newly written file from disk, rollback the session, and re-raise the error so the old resume remains completely intact.
      8. `delete old file`: ONLY after successful DB commit, delete `old_file_path` from disk (if it existed and differs from new path).
  - `get_user_resume(db: AsyncSession, current_user: User) -> Resume`:
    - Queries active resume for `current_user.id`. Raises `NotFoundError` if absent.
  - `update_parsed_data(db: AsyncSession, current_user: User, update_data: ResumeParsedDataUpdateRequest) -> Resume`:
    - Merges candidate edits into `resume.parsed_data` and commits.
  - `delete_resume(db: AsyncSession, current_user: User) -> None`:
    - Deletes file from disk and removes row from DB.
- Create `backend/app/api/v1/endpoints/resumes.py`:
  - `POST /upload` (with `@limiter.limit("5/minute")` and `UploadFile`)
  - `GET /me`
  - `PUT /me/parsed`
  - `DELETE /me`
- Mount resumes router in `backend/app/api/v1/router.py`.

### Task 4: Integration Tests

  - Validates Pydantic schema deserialization.
  - Tests 1 retry on network timeout.
  - Tests clean HTTP 503 on unrecoverable error.
- Create `backend/tests/test_resume_endpoints.py`:
  - `POST /api/v1/resumes/upload` creates resume and atomically replaces previous upload.
  - Test atomic failure: If Gemini parsing or extraction fails on new upload, the previous resume file and DB record remain intact and accessible via `GET /me`.
  - `GET /api/v1/resumes/me` returns current candidate resume and skills.
  - `PUT /api/v1/resumes/me/parsed` overrides skills and experience years.
  - `DELETE /api/v1/resumes/me` deletes disk file and database record.
  - Rate limiting verification.
