# Phase 04: Plan 01 — Interview ORM Models, Migration, Schemas & Role Presets Catalog

**Implement SQLAlchemy 2.0 `InterviewSession` and `InterviewQuestionTurn` models matching `BACKEND_SCHEMA.md` §2.6/§2.7 with Alembic migration `003_create_interview_tables.py`, Pydantic DTO schemas, and the curated Role Presets Catalog API.**

---

## Tasks

### Task 1: Interview ORM Models & Alembic Migration
- Create `backend/app/models/interview.py`:
  - `InterviewSession` (`__tablename__ = "interview_sessions"`):
    - `id`: `String(36)`, PK
    - `user_id`: `String(36)`, FK -> `users.id` ON DELETE CASCADE
    - `resume_id`: `String(36)`, FK -> `resumes.id` ON DELETE SET NULL (Nullable)
    - `target_role`: `String(100)`, nullable=False
    - `seniority_level`: `String(50)`, nullable=False (`"junior" | "mid" | "senior"`)
    - `interview_focus`: `String(50)`, nullable=False (`"Technical Core" | "System Design" | "Behavioral"`)
    - `custom_job_desc`: `Text`, nullable=True
    - `parsed_jd_data`: `JSON().with_variant(JSONB, "postgresql")`, nullable=True
    - `focus_skills`: `JSON().with_variant(JSONB, "postgresql")`, nullable=True
    - `practice_mode`: `String(50)`, nullable=False, default=`"full"`
    - `planned_core_questions`: `Integer`, nullable=False, default=6
    - `max_total_turns`: `Integer`, nullable=False, default=9
    - `current_turn_index`: `Integer`, nullable=False, default=0
    - `status`: `String(50)`, nullable=False, default=`"in_progress"`
    - `started_at`: `DateTime(timezone=True)`, server_default=func.now(), nullable=False
    - `completed_at`: `DateTime(timezone=True)`, nullable=True
    - Relationships: `user`, `resume`, `turns` (cascade delete orphan)
  - `InterviewQuestionTurn` (`__tablename__ = "interview_question_turns"`):
    - `id`: `String(36)`, PK
    - `session_id`: `String(36)`, FK -> `interview_sessions.id` ON DELETE CASCADE
    - `turn_index`: `Integer`, nullable=False
    - `question_type`: `String(50)`, nullable=False, default=`"core"`
    - `question_text`: `Text`, nullable=False
    - `candidate_answer`: `Text`, nullable=True
    - `is_follow_up`: `Boolean`, nullable=False, default=False
    - `parent_turn_id`: `String(36)`, FK -> `interview_question_turns.id`, nullable=True (self-ref)
    - `ideal_answer`: `Text`, nullable=True
    - `turn_duration_sec`: `Integer`, nullable=True
    - `created_at`: `DateTime(timezone=True)`, server_default=func.now(), nullable=False
    - Relationship: `session`, `parent_turn`, `follow_up_turns`
- Update `backend/app/models/user.py` and `backend/app/models/resume.py` to link relationships.
- Register models in `backend/app/db/base.py`.
- Create Alembic migration `backend/alembic/versions/003_create_interview_tables.py`.

### Task 2: Pydantic DTO Schemas
- Create `backend/app/schemas/interview.py`:
  - `SeniorityLevel`: Enum (`"junior"`, `"mid"`, `"senior"`)
  - `InterviewFocus`: Enum (`"Technical Core"`, `"System Design"`, `"Behavioral"`)
  - `PracticeMode`: Enum (`"full"`, `"quick"`)
  - `RolePresetItem`: `role_id: str`, `title: str`, `description: str`, `default_skills: list[str]`, `recommended_seniority: list[str]`
  - `PresetsCatalogResponse`: `roles: list[RolePresetItem]`, `seniority_levels: list[dict]`, `focus_areas: list[dict]`, `practice_modes: list[dict]`, `pacing_guidelines: dict`
  - `InterviewSessionCreateRequest`:
    - `target_role: str = Field(..., min_length=2, max_length=100)`
    - `seniority_level: SeniorityLevel`
    - `interview_focus: InterviewFocus`
    - `practice_mode: PracticeMode = PracticeMode.full`
    - `custom_job_desc: Optional[str] = Field(None, max_length=10000)`
    - `focus_skills: Optional[list[str]] = Field(default_factory=list)`
  - `InterviewSessionResponse`:
    - `id: str`, `user_id: str`, `resume_id: Optional[str]`, `target_role: str`, `seniority_level: str`, `interview_focus: str`, `practice_mode: str`, `planned_core_questions: int`, `max_total_turns: int`, `current_turn_index: int`, `status: str`, `focus_skills: Optional[list[str]]`, `started_at: datetime`, `completed_at: Optional[datetime]`
    - `model_config = ConfigDict(from_attributes=True)`

### Task 3: Presets Catalog Service & Implementation
- Create `backend/app/services/interview_presets.py`:
  - `get_presets_catalog() -> PresetsCatalogResponse`: Returns curated catalog of 7 technical role presets, seniority levels, focus options, practice modes (`full` vs `quick`), and time budgets (120s vs 180s).

### Task 4: Unit & Presets Integration Tests
- Create `backend/tests/test_interview_presets.py`:
  - Validates `get_presets_catalog` structure, role definitions, default skill tags, and pacing guidelines.
  - Tests schema validation on `InterviewSessionCreateRequest` (valid/invalid role lengths, valid enums, 10,000 char max on JD).
