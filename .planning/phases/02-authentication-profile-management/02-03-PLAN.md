<threat_model>
### Security Threat Model (ASVS L1)
- **T-02-07 (Silent Account Hijacking via OAuth Collision):** Risk of an attacker creating a Google account with a victim's email to hijack an existing password-based account. Mitigation: Silent account merge is strictly rejected; API returns HTTP 400 `ACCOUNT_LINKING_REQUIRED`. The user must log in with their local password first and explicitly confirm linking.
- **T-02-08 (Insecure Password Reset Tokens):** Risk of reset token guessing or replay. Mitigation: Use 32-byte cryptographically secure URL-safe tokens (`secrets.token_urlsafe(32)`), store only SHA-256 hash in DB, enforce single-use (`used = True`), and apply strict 15-minute expiration.
- **T-02-09 (Account Enumeration via Password Reset):** Risk of discovering registered email addresses. Mitigation: `POST /password-reset/request` always returns a generic 200 OK message regardless of whether the email exists.
</threat_model>

<task type="auto">
  <name>Task 2: Implement Google OAuth, Profile Management, and Password Reset in AuthService and Endpoints</name>
  <files>backend/app/services/auth_service.py, backend/app/api/v1/endpoints/auth.py, backend/app/api/v1/router.py</files>
  <read_first>backend/app/services/auth_service.py, backend/app/api/v1/endpoints/auth.py, docs/TRD.md, docs/APP_FLOW.md</read_first>
  <action>
    1. Update `backend/app/services/auth_service.py`:
       - `verify_google_id_token(id_token: str) -> dict`: Uses `google.oauth2.id_token.verify_oauth2_token` with Google `Request` transport and `settings.GOOGLE_CLIENT_ID` (if set) to extract `sub`, `email`, `name`. In test/development mode with dummy tokens or mock client, permits testing mocks.
       - `authenticate_google_user(db, id_token: str) -> (User, str, str)`: Verifies token. Looks up existing `UserOAuthIdentity` with `provider_user_id == sub`. If found, issues access token + refresh token. If not found, checks if `User` with `email` exists: if exists, raises `ValidationError("This email is already registered with a password. Please sign in with your password first.", error_code="ACCOUNT_LINKING_REQUIRED")`. If no user exists, creates new `User` with `auth_provider="google"`, creates `UserOAuthIdentity`, issues tokens.
       - `link_google_account(db, current_user: User, id_token: str) -> User`: Verifies token. Ensures `provider_user_id` not already linked to another account. Creates `UserOAuthIdentity` row.
       - `update_user_profile(db, current_user: User, update_data) -> User`: Updates `full_name`, `target_role`, `experience_level`, `bio`.
       - `request_password_reset(db, email: str)`: Looks up user. If found, generates 32-byte secure token, computes SHA-256 hash, creates `PasswordResetToken` (15-min expiry). If `settings.ENVIRONMENT in ("development", "testing")`, logs clickable URL `http://localhost:5173/reset-password?token={raw_token}` to logger.
       - `confirm_password_reset(db, token: str, new_password: str)`: Computes SHA-256 hash of token, finds matching `PasswordResetToken`. If missing, expired, or `used == True`, raises `ValidationError("Invalid or expired reset token", error_code="INVALID_RESET_TOKEN")`. Updates user password with bcrypt hash, marks reset token `used = True`, revokes all active `refresh_tokens` for that user.
    2. Update `backend/app/api/v1/endpoints/auth.py`:
       - `POST /google`: Accepts `GoogleAuthRequest`, calls `authenticate_google_user`, returns `TokenResponse`, sets cookie.
       - `POST /google/link`: Authenticated route (`Depends(get_current_user)`). Accepts `AccountLinkConfirmRequest`, links identity, returns `UserResponse`.
       - `GET /me`: Authenticated route. Returns `UserResponse(current_user)`.
       - `PUT /me`: Authenticated route. Accepts `UserProfileUpdateRequest`, updates and returns `UserResponse`.
       - `POST /password-reset/request`: Accepts `PasswordResetRequest`, triggers reset, returns `MessageResponse("If an account with that email exists, password reset instructions have been dispatched")`.
       - `POST /password-reset/confirm`: Accepts `PasswordResetConfirmRequest`, confirms reset, returns `MessageResponse("Password has been reset successfully. Please log in with your new password.")`.
    3. Update `backend/app/api/v1/router.py`:
       - Mount `auth.router` with `prefix="/auth"`, `tags=["Authentication"]`.
  </action>
