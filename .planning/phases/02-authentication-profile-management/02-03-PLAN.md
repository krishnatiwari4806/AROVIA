<threat_model>
### Security Threat Model (ASVS L1)
- **T-02-09 (Silent Account Hijacking via OAuth Collision):** Risk of an attacker creating a Google account with a victim's email to hijack an existing password-based account. Mitigation: Silent account merge is strictly rejected; API returns HTTP 400 `ACCOUNT_LINKING_REQUIRED`. The user must log in with their local password first and explicitly confirm linking via authenticated endpoint.
- **T-02-10 (Forged or Unverified Google Tokens):** Risk of forged or unverified OAuth identities. Mitigation: Google ID token verification always calls `google.oauth2.id_token.verify_oauth2_token()` validating cryptographic signature against live Google JWKS, audience matching `GOOGLE_CLIENT_ID`, valid issuer, expiry, and `email_verified is True`. Fails closed if `GOOGLE_CLIENT_ID` is unset.
- **T-02-11 (Insecure Password Reset Tokens & Replay):** Risk of reset token guessing or replay. Mitigation: 32-byte cryptographically secure URL-safe tokens, only SHA-256 hash stored in DB, strict 15-minute expiration, single-use enforcement (`used = True`), and invalidation of any prior active reset tokens upon new request.
- **T-02-12 (Account Enumeration via Password Reset):** Risk of discovering registered email addresses. Mitigation: `POST /password-reset/request` always returns a generic 200 OK message without exposing the token in the response payload.
</threat_model>

  <name>Task 2: Implement Google OAuth, Profile Management, and Password Reset in AuthService and Endpoints</name>
  <files>backend/app/services/auth_service.py, backend/app/api/v1/endpoints/auth.py, backend/app/api/v1/router.py</files>
  <read_first>backend/app/services/auth_service.py, backend/app/api/v1/endpoints/auth.py, docs/TRD.md, docs/APP_FLOW.md</read_first>
  <action>
    1. Update `backend/app/services/auth_service.py`:
       - `verify_google_id_token(id_token: str) -> dict`: If not `settings.GOOGLE_CLIENT_ID`, raises `AppError("Google Sign-In is not configured on this server.", status_code=500, error_code="GOOGLE_AUTH_UNCONFIGURED")`. Calls `id_token.verify_oauth2_token(token, google_requests.Request(), settings.GOOGLE_CLIENT_ID)`. Validates issuer is in `("accounts.google.com", "https://accounts.google.com")`, `sub` is non-empty, `email` is present, and `email_verified is True`.
       - `authenticate_google_user(db, id_token: str) -> (User, str, str)`: Verifies token. Looks up existing `UserOAuthIdentity` with `provider_user_id == sub`. If found, issues access token + refresh token. If not found, checks if `User` with `email` exists: if exists, raises `ValidationError("This email is already registered with a password. Please sign in with your password first.", error_code="ACCOUNT_LINKING_REQUIRED")`. If no user exists, creates new `User` with `auth_provider="google"`, creates `UserOAuthIdentity`, issues tokens.
       - `link_google_account(db, current_user: User, id_token: str) -> User`: Verifies token. Ensures `provider_user_id` is not already linked to another account (raises `ConflictError` if so). Creates `UserOAuthIdentity` row.
       - `update_user_profile(db, current_user: User, update_data) -> User`: Updates `full_name`, `target_role`, `experience_level`, `bio`.
       - `request_password_reset(db, email: str)`: Looks up user. If found, marks all existing active `PasswordResetToken` records for this user as `used = True` (invalidates previous tokens). Generates 32-byte secure token, computes SHA-256 hash, inserts new `PasswordResetToken` (15-min expiry). If `settings.ENVIRONMENT in ("development", "testing")`, logs clickable URL `http://localhost:5173/reset-password?token={raw_token}` to logger. (Never returns raw token).
       - `confirm_password_reset(db, token: str, new_password: str)`: Computes SHA-256 hash of token, finds matching `PasswordResetToken`. If missing, expired, or `used == True`, raises `ValidationError("Invalid or expired reset token", error_code="INVALID_RESET_TOKEN")`. Updates user password with bcrypt hash, marks reset token `used = True`, revokes all active `refresh_tokens` for that user (`revoked = True`).
    2. Update `backend/app/api/v1/endpoints/auth.py`:
       - `POST /google`: Accepts `GoogleAuthRequest`, calls `authenticate_google_user`, returns `TokenResponse`, sets cookie.
       - `POST /google/link`: Authenticated route (`Depends(get_current_user)`). Accepts `AccountLinkConfirmRequest`, links identity, returns `UserResponse`.
       - `GET /me`: Authenticated route. Returns `UserResponse(current_user)`.
       - `PUT /me`: Authenticated route. Accepts `UserProfileUpdateRequest`, updates and returns `UserResponse`.
       - `POST /password-reset/request`: Accepts `PasswordResetRequest`, triggers reset, returns `MessageResponse("If an account with that email exists, password reset instructions have been dispatched")`.
       - `POST /password-reset/confirm`: Accepts `PasswordResetConfirmRequest`, confirms reset, returns `MessageResponse("Password has been reset successfully. Please log in with your new password.")`.
    3. Update `backend/app/api/v1/router.py`:
       - Mount `auth.router` with `prefix="/auth"`, `tags=["Authentication"]`.
  </action>
