<threat_model>
### Security Threat Model (ASVS L1)
- **T-02-01 (Weak Password Hashing):** Risk of fast brute-force dictionary attacks if weak hash functions (e.g. MD5/SHA1/plain SHA256) are used for user passwords. Mitigation: Enforce salted `bcrypt` with cost factor 12 via `passlib.context.CryptContext`.
- **T-02-02 (Raw Token Persistence):** Risk of session hijacking if database backups leak raw refresh tokens or password reset tokens. Mitigation: Only SHA-256 hashes (`token_hash`) of refresh and reset tokens are saved in the database; raw tokens are never persisted.
- **T-02-03 (Timing Attacks):** Risk of timing side-channel attacks on password and token comparison. Mitigation: Use constant-time comparison in `pwd_context.verify()` and constant-time string hashing.
</threat_model>

       - `pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")`
       - `hash_password(password: str) -> str`: Hashes password using bcrypt.
       - `verify_password(plain_password: str, hashed_password: str) -> bool`: Verifies password against hash.
       - `hash_token(token: str) -> str`: Computes `hashlib.sha256(token.encode('utf-8')).hexdigest()`.
       - `generate_secure_token(nbytes: int = 32) -> str`: Returns `secrets.token_urlsafe(nbytes)`.
       - `create_access_token(subject: str, expires_delta: Optional[timedelta] = None) -> str`: Encodes JWT with `sub`, `exp` (15 min default), `type="access"` using `settings.SECRET_KEY` and `settings.ALGORITHM`.
       - `decode_access_token(token: str) -> dict`: Decodes and validates JWT signature and expiry.
