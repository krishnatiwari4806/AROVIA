# Phase 07: Plan 01 — Visual Analytics Components, Radar Chart, Score Badges & Strengths/Growth Cards

**Install client-side export dependencies, implement the 4-tier competency rubric, build the pure SVG Radar Polygon Chart, horizontal dimensional progress bars, header score gauge, and evidence-backed strengths/growth cards.**

---

## Tasks

### Task 1: Dependencies & Design Tokens
- Update `frontend/package.json` with `jspdf` and `html2canvas` and install via `npm install`.
- Update `frontend/src/index.css` with report card styles:
  - Metric bars, radial gauges, radar chart containers.
  - Emerald, Blue, Amber, and Rose badge styles.
  - Strengths and improvement cards layout.

### Task 2: Competency Rubric Helper (`frontend/src/utils/competencyRubric.js`)
- Implement `getCompetencyTier(score: number)`:
  - 85–100: `Exceptional / Strong Hire` (`emerald`)
  - 70–84: `Proficient / Solid Hire` (`blue`)
  - 50–69: `Developing / Needs Practice` (`amber`)
  - <50: `Needs Substantial Preparation` (`rose`)
- Implement `getSeniorityBenchmark(seniorityLevel: string)`:
  - Senior: 85, Mid: 70, Junior: 55.

### Task 3: Pure SVG Multi-Axis Radar Chart & Metric Bars
- Create `frontend/src/components/report/RadarChart.jsx`:
  - Pure SVG polygon calculation for 5 axes: Relevance, Correctness, Keywords, Clarity, Confidence.
  - Renders 5 concentric grid rings (20%, 40%, 60%, 80%, 100%).
  - Overlays Target Seniority Benchmark polygon with dashed line.
  - Overlays Candidate Score polygon with glowing gradient fill and vertex dots.
  - Axis labels with dimension names and values.
- Create `frontend/src/components/report/MetricBar.jsx`:
  - 5 horizontal progress bars with animated fill, percentage badges, and dimension descriptions.

### Task 4: Report Card Header Component
- Create `frontend/src/components/report/ReportHeader.jsx`:
  - Candidate Target Role, Seniority Tier, Practice Mode, and completion date.
  - Overall Composite Score (0–100) with radial ring indicator.
  - Competency tier badge with color-coded styling.
  - Executive summary blockquote.

### Task 5: Strengths & Growth Areas Component
- Create `frontend/src/components/report/StrengthsImprovements.jsx`:
  - Top 3–5 Strengths cards with evidence turn indicators and green checkmark icons.
  - Top 3–5 Improvement cards with gap descriptions, concrete study advice, and target topic highlights.
