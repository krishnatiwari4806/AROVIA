# Phase 07: Plan 02 — Turn-by-Turn Accordion Review, Client-Side PDF Export Engine & Full Report Card View

**Implement the expandable turn-by-turn Q&A accordion review with concept matrix diffs, client-side multi-page A4 PDF export with `jspdf` and `html2canvas`, and the full `ReportCard.jsx` container integrated with the mock interview room.**

---

## Tasks

### Task 1: Turn-by-Turn Accordion Review (`TurnAccordion.jsx`)
- Create `frontend/src/components/report/TurnAccordion.jsx`:
  - Collapsible cards for each interview turn.
  - Header: Turn index ("Turn 1: Core", "Turn 2: Follow-up"), question prompt preview, turn composite score badge, and chevron toggle.
  - Expanded content:
    - Candidate Answer (styled text area).
    - Benchmark Senior Ideal Answer (distinct highlighted background).
    - Ideal Answer Comparison diff.
    - Concept Matrix: Green pill badges for `covered_concepts` and Amber/Red pill badges for `missed_concepts`.
    - Turn-Level Mini Score Meters (Relevance, Correctness, Keywords, Clarity, Confidence).
    - Speech Stats: Duration in seconds, filler word count, and filler density percentage.
    - Constructive takeaway feedback banner.

### Task 2: Client-Side PDF Export Utility (₹0 Cost)
- Create `frontend/src/utils/pdfExport.js`:
  - Captures `#report-card-container` using `html2canvas` at 2x scale.
  - Formats and splits into standard multi-page A4 PDF using `jspdf`.
  - Downloads file `AROVIA_Interview_Report_<Role>_<Date>.pdf`.
  - Fallback to `window.print()` if canvas capture fails or for immediate printing.
- Create `frontend/src/components/report/PDFExportButton.jsx`:
  - Action button with downloading spinner and error handling.

### Task 3: API Service Integration & Full Report Card Container
- Update `frontend/src/services/api.js`:
  - Add `getSessionEvaluation(sessionId)` (`GET /interviews/sessions/{id}/evaluation`).
  - Add `evaluateSession(sessionId)` (`POST /interviews/sessions/{id}/evaluate`).
- Create `frontend/src/components/report/ReportCard.jsx`:
  - Fetches evaluation data on mount with loading skeleton and error retry state.
  - Assembles `ReportHeader`, `RadarChart`, `MetricBar`, `StrengthsImprovements`, `TurnAccordion`, and `PDFExportButton`.
  - Action buttons: "Download PDF Report", "Print Report", "Start New Interview".

### Task 4: Connect Interview Room & App Shell
- Update `frontend/src/components/interview/InterviewRoom.jsx`:
  - "View Evaluation Report" button on interview completion screen switches directly to `<ReportCard sessionId={sessionId} onRetake={...} />`.
- Update `frontend/src/App.jsx` to support testing and viewing Report Card mode.

### Task 5: Production Build & Test Suite Verification
- Verify clean frontend build via `npm run build`.
- Run full backend regression test suite.
