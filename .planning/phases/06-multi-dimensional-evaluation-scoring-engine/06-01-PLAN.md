# Phase 06: Plan 01 — Evaluation Models, Schemas, Local Heuristics & Gemini Evaluator

**Implement database evaluation columns, Alembic migration, local filler-word NLP heuristics, Pydantic DTO schemas, and Gemini structured multi-dimensional evaluation service.**

---

## Tasks

### Task 1: ORM Models & Alembic Migration
- Update `backend/app/models/interview.py`:
  - In `InterviewSession`:
    - `overall_score`: Integer, nullable
    - `dimension_scores`: JSON / JSONB, nullable
    - `evaluation_report`: JSON / JSONB, nullable
  - In `InterviewQuestionTurn`:
    - `relevance_score`: Integer, nullable
    - `correctness_score`: Integer, nullable
    - `keywords_score`: Integer, nullable
    - `clarity_score`: Integer, nullable
    - `confidence_score`: Integer, nullable
    - `turn_score`: Integer, nullable
    - `evaluation_data`: JSON / JSONB, nullable
- Create Alembic migration `backend/alembic/versions/004_add_evaluation_fields.py`.

### Task 2: Local Filler-Word Heuristic Analyzer (₹0 Cost)
- Create `backend/app/services/evaluation_heuristics.py`:
  - `analyze_speech_confidence(text: str) -> dict`:
    - Scans for filler words and hesitation markers: `um`, `uh`, `er`, `ah`, `like`, `you know`, `sort of`, `kind of`, `i guess`, `i think maybe`, `basically`, `honestly`, `actually`, `probably`, `not sure`.
    - Computes `filler_count`, `total_words`, `filler_density`.
    - Calculates `heuristic_confidence_score` (0–100).
    - Returns metrics dict.

### Task 3: Pydantic DTO Schemas
- Create `backend/app/schemas/evaluation.py`:
  - `TurnEvaluationItem`: `turn_index`, `relevance_score`, `correctness_score`, `keywords_score`, `clarity_score`, `confidence_score`, `covered_concepts`, `missed_concepts`, `ideal_answer_comparison`, `turn_feedback`.
  - `StrengthItem`: `title`, `description`, `evidence_turn_index`.
  - `ImprovementItem`: `title`, `description`, `actionable_recommendation`, `evidence_turn_index`.
  - `SessionEvaluationReport`: `turns_evaluation: List[TurnEvaluationItem]`, `top_strengths: List[StrengthItem]`, `top_improvements: List[ImprovementItem]`, `executive_summary: str`.
  - `SessionEvaluationReportResponse`: Complete API response DTO including `overall_score`, `dimension_scores`, `turns_evaluation`, `top_strengths`, `top_improvements`, `executive_summary`, `completed_at`.

### Task 4: Gemini Structured Evaluation Service
- Update `backend/app/services/gemini_service.py`:
  - Add `SESSION_EVALUATION_PROMPT_TEMPLATE`:
    - Ingests role, seniority, focus, JD context, resume context, and full transcript turns (questions, candidate answers, ideal answers).
    - Instructs Gemini to evaluate 5 dimensions (0–100), extract covered vs missed concepts, compare vs ideal answers, extract top 3–5 strengths, 3–5 prioritized improvements with concrete study advice, and write an executive summary.
    - Uses `response_schema=SessionEvaluationReport`.
  - Implement `evaluate_interview_session(...) -> SessionEvaluationReport` with 1 retry and fallback.

### Task 5: Unit Tests for Heuristics & Evaluation Engine
- Create `backend/tests/test_evaluation_heuristics.py`:
  - Test filler word detection on clean text vs filler-heavy text.
  - Test confidence heuristic score clamping (0–100).
- Create `backend/tests/test_evaluation_engine.py`:
  - Test Gemini session evaluation prompt formulation and structured output validation.
  - Test fallback evaluation resilience on transient AI failure.
